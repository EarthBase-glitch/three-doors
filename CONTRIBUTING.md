# Contributing to Three Doors

Thanks for wanting to help build this out. There are two ways in — pick
whichever fits:

## Add lore — no coding required

Play through the site, choose a door, and once you've built your
character, use **"Read & add to lore"** to submit your own scene for
Heaven, Hell, or Reincarnation right there on the live site. Submissions
are reviewed before they're shown to anyone else, so it might take a
little while to appear.

## Contribute code

1. Fork this repository.
2. Create your own free Firebase project (Firestore + Authentication with
   the Email/Password provider enabled) so you have a sandbox to test
   against — see `README.md` for the steps. Put your own project's values
   in your local copy of `firebase-config.js`; never commit real
   production credentials.
3. Serve the folder locally to test (for example `npx serve .`) and open
   `index.html`.
4. Open a pull request describing what you changed and why.

By submitting a pull request, you agree that your contribution may be
used, modified, and distributed as part of this project — see `LICENSE`.
